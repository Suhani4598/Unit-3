======Description Of Each Program======

1. Function Overloading

This program demonstrates compile-time polymorphism using function overloading. Multiple add() functions perform addition with different numbers or types of arguments.

2. Area Calculator Using Function Overloading

This program calculates the area of different shapes using overloaded functions. The function selected depends on the number and type of arguments provided.

3. Unary Minus Operator Overloading

This program demonstrates unary operator overloading. The minus operator is overloaded to change a stored number into its negative value.

4. Prefix and Postfix Increment

This program demonstrates prefix and postfix increment operator overloading. Prefix increments the value before returning it, while postfix returns the old value and then increments it.

5. Binary + Operator for Complex Numbers

This program demonstrates binary operator overloading by adding two complex numbers using the + operator.

6. Relational Operator Overloading

This program overloads the > operator to compare two Distance objects. It determines which distance is greater.

7. Friend/Non-Member Operator Overloading

This program demonstrates operator overloading using a friend non-member function. It allows an integer to be added to a complex number and accesses the class's private data.

8. Base Pointer Without Virtual Function

This program demonstrates static binding. When a base pointer points to a derived object, the base-class function is called because the function is not virtual.

9. Base Pointer With Virtual Function

This program demonstrates run-time polymorphism. A base pointer can point to different derived objects, and the appropriate overridden function is called because the function is virtual.

10. Base Reference With Virtual Function

This program demonstrates run-time polymorphism using a base-class reference. The reference can refer to different derived objects, and the correct area() function is selected at run time.

11. Abstract Class and Pure Virtual Function

This program demonstrates an abstract class using a pure virtual function. The Shape class provides the interface, while the Rectangle class implements the area calculation.

12. Collection of Polymorphic Shape Pointers

This program stores different shape objects through a common Shape interface. It uses polymorphism to call the correct area function for each shape.

13. Virtual Destructor

This program demonstrates the importance of a virtual destructor. When a derived object is deleted through a base pointer, both the derived and base destructors execute correctly.

14. Object Slicing

This program demonstrates object slicing. When a derived object is passed by value as a base object, the derived part is lost. Passing it by reference preserves the derived object.

15. Payment Processing System

This program demonstrates a real-world application of run-time polymorphism. Card, UPI, and Net Banking payments use the same Payment interface but provide different payment implementations.
